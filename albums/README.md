# Albums

Family albums and scrapbooks photographed whole, page by page, kept together as they were
received. Each album has a folder of its own, named for the book it becomes in the archive
(`books/<slug>/` there), and keeps the camera's own file names, which run in the order the pages
were photographed.

```
albums/<slug>/IMG_####.JPEG    every photograph of the album: whole pages, close-ups of single
                               pictures, and the pieces of a long clipping shot one by one
albums/<slug>/<part>/…         photographs of other books kept with it as an addendum
```

Nothing here is a Gallery picture. Which photograph shows which page, and what each holds, is
kept with the archive (`research/` and `books/<slug>/`). A picture or clipping chosen for the
Gallery is cropped from these originals and filed in `gallery/files/` under its record's id.
